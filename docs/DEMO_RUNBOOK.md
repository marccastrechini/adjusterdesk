# Demo Runbook

## Demo Purpose
Provide a practical, plain-language walkthrough of AdjusterDesk for small public adjusting offices and collect concrete usability and workflow feedback.

## Target Audience
Solo to 5-person public adjusting offices currently managing work with spreadsheets, email, text messages, calendar reminders, and memory.

## Demo Environment Notes
- Environment: production demo workspace on https://adjusterdesk.xyz
- Verified baseline:
  - HEAD and origin/main at e6fbb09
  - Latest production build active
  - Demo rehearsal completed with no production blockers
- Presenter account: Demo Owner (production demo user)
- Keep the walkthrough focused on current workflows, not roadmap features.

## Safety Notes
- Do not run production demo bootstrap.
- Do not run reset, seed, or data refresh commands on production.
- Production contains the Stark Loss workspace; preserve all existing production data.
- If demonstrating conversion actions, avoid submitting mutations unless intentionally planned for that session.

## Recommended Demo Script
1. Start on Today.
2. Open lead follow-ups.
3. Show lead details, tasks, and notes.
4. Show Convert to claim without submitting unless intentionally demoing mutation.
5. Open an existing active claim.
6. Show claim overview.
7. Show Documents request/upload paths.
8. Show Client Status internal page.
9. Open public client status page.
10. Show Money page: settlement, check, fee invoice, balance.
11. Show Templates & Checklists.
12. Return to Today and close with the daily command-center message.

## Close Message
"AdjusterDesk is built to be the daily command center for your office: what to follow up, what is waiting, what is due, and what is still unpaid."

## Suggested Demo Timing (Optional)
- Intro and framing: 2 minutes
- Today + Leads + Claim flow: 10-12 minutes
- Client status + Money + Templates: 8-10 minutes
- Feedback capture: 5-10 minutes
